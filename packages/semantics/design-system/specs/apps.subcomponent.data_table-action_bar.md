# DataViews.ActionBar

- **IRI (unchanged):** `ds:apps.subcomponent.data_table-action_bar`; implementations keep `@implements ds:apps.subcomponent.data_table-action_bar`.
- **Name (`ds:name`):** DataViews.ActionBar, was DataTable.ActionBar.
- **Parent (`ds:parentComponent`):** `ds:apps.pattern.data_views`, was `ds:apps.pattern.datatable`.
- **Properties:** selection-mode, bulk-actions and on-bulk-action are inherited from DataViews.

## Summary (`ds:summary`)

When one or more records are selected, the action bar appears at the bottom of the view, with the bulk actions defined for that view and a deselect button on the far right. With persistent selection, it also shows the number of selected items, such as "5 Selected". Use it to delete, export or tag several records at once.
